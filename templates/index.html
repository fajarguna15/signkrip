Tanda Tangan Digital Dokumen (PDF, Word, TXT)

Tandatangani berkas dokumen (PDF, Word .doc/.docx, atau Teks .txt). Untuk PDF, QR Code & metadata disisipkan ke dalam file. Untuk Word dan TXT, sistem mengunduh bukti tanda tangan .signkrip.

Pilih Dokumen & Metadata Penandatangan
Pilih atau seret berkas PDF, Word, atau TXT ke sini
Hanya mendukung format PDF, Word (.doc/.docx), dan Teks (.txt)
Pengaturan Posisi QR Code (Khusus PDF)
📌 PDF: QR Code disisipkan ke halaman PDF. Word & TXT: Sistem menghasilkan file bukti .signkrip yang berisi QR Code dan bukti kriptografi.
💡 Tips: Untuk file PDF, koordinat (0,0) dimulai dari pojok kiri bawah.

Verifikasi Keaslian Dokumen (PDF, Word, TXT)

Unggah file PDF bertanda tangan ATAU berkas Word/TXT beserta berkas bukti tanda tangan .signkrip untuk memverifikasi keaslian dan integritas dokumen.

Unggah Berkas Verifikasi
Pilih atau seret berkas PDF, Word, atau TXT di sini
File PDF bertanda tangan ATAU berkas Word (.doc/.docx) / TXT
Pilih berkas bukti .signkrip (jika memverifikasi berkas Word/TXT)
📌 Sistem akan membaca bukti tanda tangan digital dan memverifikasi bahwa tidak ada satu karakter/byte pun yang diubah dari berkas asli.

Tentang Aplikasi SignKrip

Spesifikasi teknis backend Python Cryptography & fitur keamanan sistem

ℹ️ Informasi Sistem
Nama Aplikasi SignKrip Digital Signature (Python Flask)
Versi 2.0.0 (Python Flask & cryptography Engine)
Backend Framework Python 3.14 + Flask 3.1
Library Kriptografi cryptography 50.0.1 (Hazmat primitives)
Spesifikasi Kunci RSA 2048-bit (PSS Scheme) & ECDSA P-256 (secp256r1)
Pengunci Kunci Privat PBKDF2 100,000 Iterasi + AES-256-GCM
Hash Dokumen SHA-256 Cryptographic Hash
Format Tanda Tangan Base64 PKCS#8 & SPKI Standard
